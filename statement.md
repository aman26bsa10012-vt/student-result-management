# Project Framework Specification: statement.md

## 1. Problem Statement
Educational institutions often struggle to maintain student academic records efficiently without using heavy, cloud-based graphical systems. These bulky software suites consume high system memory and carry external database dependencies that complicate local deployment. Teachers need a quick, distraction-free environment to insert grades, remove stale profiles, and run instant statistical calculations. This project introduces a lightweight, text-driven Student Record Engine built entirely in local Python files to handle data management tasks efficiently from a local command terminal.

## 2. Scope of the Project
The application is scoped to process school ledger tracking data locally for isolated administrator profiles. It stores all information inside human-readable flat-text repositories rather than running external engine management layers.
* Administrator identity verification loops.
* Student academic registry creations (CRUD infrastructure).
* Core aggregate score assessment calculations.
* High-level institutional grade distribution reporting matrices.

## 3. Target Users
* Course instructors and teachers managing small-to-medium class groups.
* Academic coordinators requiring immediate local mark calculations.
* System managers looking for an unbloated academic data entry utility.

## 4. High-Level Features
* Custom Pointer State-Machine File Reader.
* Native Array-Offset Encryption Masking for Passwords.
* Built-in Mark Calculator Engine (Grades A+ through F).
* Class Analytics Matrix (Class Averages and Topper Tracking).
